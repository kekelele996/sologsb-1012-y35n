# SignCourse Studio · 手语课程双档案工作台

SignCourse Studio 把原先合订在一份本地稿里的内容拆成两份各自维护的档案：

- **编排台**：教研组维护课程模块、学习步骤和带编号的学习检查点；
- **学习档案**：教研组另记的学员档案，维护学员名册、按检查点编号登记的掌握记录和结业结论。

## 功能

### 编排台（课程模块 / 学习步骤 / 检查点）

- 课程模块：创建多个模块，维护模块目标、主题色和学习步骤。
- 步骤编排：每个步骤支持示范、讲解、练习类型，以及时长和入门/进阶/挑战难度标签。
- 检查点：每个步骤下维护带编号（如 `CP-01`）、标题、所在秒数的检查点；编号是掌握记录挂接检查点的凭据。
- 动作素材：记录示范片段名称、可选的本地素材地址、手形说明、主要动作区域和镜头角度。
- 字幕与无障碍：设置字幕文本、字幕位置和替代文本，并在预览中标记字幕与动作区域冲突。
- 学习依赖：选择前置步骤，检查前置项不存在或指向后续步骤的跳级问题。
- 练习设计：记录练习任务、反馈方式和常见错误清单。
- 设备预览：在手机 9:16 和平板 4:3 视图间切换，时间线上标注各检查点位置。
- 发布前检查：检查字幕遮挡、步骤跳级、替代文本缺失、检查点编号缺失/重复/越界等。
- 状态流转：支持草稿、提交复核、退回修改、冻结版本和基于冻结版本创建修订版。
- 离线编辑：课程稿保存在独立的 localStorage 键（`…course-project-v2`）。

### 学习档案（学员 / 掌握记录 / 结业结论）

- 学员名册：建档、班级与备注；掌握记录按编排台检查点编号登记，并保留登记时的标题快照。
- 结业结论：对学员出具「结业 / 未结业」结论。
- **检查点改动联动**：编排台检查点一被修改或删除，未结业学员挂在该检查点上的旧掌握记录立即作废（保留作废痕迹与原因），需要重新登记；**已经结业的学员记录照旧保留**。
- **断网先记**：离线时新增学员和掌握记录先写入本机待对账队列，不阻断登记。
- **按学员对账合并**：恢复联网后按学员逐个与教研组档案对账，自动上传本机改动、下载并档教研组独有的记录。
- **对不上先挂起**：同一记录双方评价不一致、学员资料或结论冲突时，该学员挂起并列出双方字段差异，不自动覆盖任何一方。
- **失败后按档案侧重试**：教研组档案不可达导致对账失败时保留队列；故障恢复或对冲突选择「按档案侧重试」时，以本机学习档案为准覆盖教研组侧。
- **旧数据升级**：旧合订稿（`…course-project-v1`）首次启动时自动拆分；旧掌握记录缺检查点编号，按检查点标题回填，标题补不上的记录在「单列待处理」区人工补绑或剔除。

### 通用

- 顶栏在「编排台 / 学习档案」两份独立档案间切换；可手动模拟断网与教研组档案故障。
- 键盘操作：`⌘/Ctrl + Z` 撤销、`⇧⌘/Ctrl + Z` 重做、`⌘/Ctrl + S` 保存草稿、`Alt + ↑/↓` 调整步骤顺序。

## 数据存储

| 内容 | 存储键 | 归属 |
| --- | --- | --- |
| 课程模块 / 步骤 / 检查点 / 冻结版本 | `sologsb-1012-sign-course-project-v2` | 编排台 |
| 学员 / 掌握记录 / 结业结论 / 待对账队列 / 挂起 | `sologsb-1012-sign-learning-archive-v1` | 学习档案 |
| 教研组档案（模拟服务端，按学员一文档） | `sologsb-1012-research-archive/<学员id>` | 对账对端 |
| 升级前的合订稿 | `sologsb-1012-sign-course-project-v1`（迁移后删除） | 旧数据 |

## 技术栈

- Stencil 4
- TypeScript 5
- Ionic 9
- Ionic Core CSS

## 开发

```bash
npm install
npm run dev
```

Stencil 开发服务器默认监听 `3333` 端口，并启用监听构建。

## 构建

```bash
npm run build
```

生产静态文件输出到 `www/`。构建会同时生成 Stencil 分发包和组件文档。

## 业务规则验证

数据层（拆分迁移、标题回填、离线对账、挂起与档案侧重试、检查点变动作废但结业保留）有独立的纯 Node 断言脚本：

```bash
npx esbuild scripts/verify-rules.ts --bundle --platform=node --format=esm --outfile=/tmp/verify-rules.mjs
node /tmp/verify-rules.mjs
```

## Docker

```bash
docker build -t sologsb-1012 .
docker run --rm -p 10012:80 sologsb-1012
```

容器内部由 nginx 监听 `80`；宿主端口按根项目端口表映射为 `10012`。
